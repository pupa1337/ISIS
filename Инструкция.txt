О клонировании репозитория
Вы можете клонировать репозиторий на GitHub.com локальный компьютер или в кодовое пространство, чтобы упростить исправление конфликтов слияний, добавление или удаление файлов, а также отправку больших коммитов. Когда вы клонируете репозиторий, вы копируете его из GitHub.com локальной машины или в удалённый виртуальный компьютер при создании кодового пространства. Для получения дополнительной информации о клонировании в кодовое пространство см. Создание пространства кода для репозитория.

Клонирование репозитория позволяет получить полную копию всех данных репозитория, которые GitHub.com имели на тот момент времени, включая все версии каждого файла и папки проекта. Вы можете перенести свои изменения в удалённый репозиторий на GitHub.com, или извлечь изменения других людей из GitHub.com. Дополнительные сведения см. в разделе С помощью Git.

Вы можете клонировать свой существующий репозиторий или существующий репозиторий другого пользователя для участия в проекте.

Клонирование репозитория
На GitHubперейдите на главную страницу репозитория.

Над списком файлов щелкните  Code.

Снимок экрана: список файлов на целевой странице репозитория. Кнопка "Код" выделена темно-оранжевым контуром.

Скопируйте URL-адрес репозитория.

Чтобы клонировать репозиторий с помощью HTTPS, в разделе "HTTPS" нажмите .

Чтобы клонировать репозиторий с помощью ключа SSH, включая сертификат, выданный центром сертификации SSH вашей организации, щелкните SSH, а затем щелкните .

Чтобы клонировать репозиторий с помощью GitHub CLI, щелкните GitHub CLI, а затем щелкните .

Снимок экрана: раскрывающееся меню "Код". Справа от URL-адреса HTTPS для репозитория значок копирования описывается темно-оранжевым цветом.

Откройте GIT Bash.

Измените текущий рабочий каталог на расположение, где должен находиться клонированный каталог.

Введите git clone и вставьте URL-адрес, скопированный ранее.

git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
Нажмите клавишу ВВОД, чтобы создать локальный клон.

$ git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
> Cloning into `Spoon-Knife`...
> remote: Counting objects: 10, done.
> remote: Compressing objects: 100% (8/8), done.
> remove: Total 10 (delta 1), reused 10 (delta 1)
> Unpacking objects: 100% (10/10), done.
Клонирование пустого репозитория
Пустой репозиторий не содержит файлов. Это часто происходит, если вы не инициализируете репозиторий с README при создании.

На GitHubперейдите на главную страницу репозитория.

Чтобы клонировать репозиторий через командную строку с помощью HTTPS, в разделе «Быстрая настройка» нажмите . Чтобы клонировать репозиторий с помощью SSH-ключа, включая сертификат, выданный SSH-центром вашей организации, нажмите SSH, затем нажмите .

Снимок экрана: заметки о быстрой настройке пустого репозитория. Справа от URL-адреса HTTPS для репозитория значок копирования выделен оранжевым цветом.

В качестве альтернативы, чтобы клонировать репозиторий в рабочем столе, нажмите  «Настроить в рабочем столе » и следуйте инструкциям, чтобы завершить клонирование.

Снимок экрана: заметки о быстрой настройке пустого репозитория. Кнопка "Настройка в рабочем столе" описана в темно-оранжевый цвет.

Откройте GIT Bash.

Измените текущий рабочий каталог на расположение, где должен находиться клонированный каталог.

Введите git clone и вставьте URL-адрес, скопированный ранее.

git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
Нажмите клавишу ВВОД, чтобы создать локальный клон.

$ git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
> Cloning into `Spoon-Knife`...
> remote: Counting objects: 10, done.
> remote: Compressing objects: 100% (8/8), done.
> remove: Total 10 (delta 1), reused 10 (delta 1)
> Unpacking objects: 100% (10/10), done.
